考试资讯

国际与香港常见计算机相关路径

面向国内、国际学校及香港学生，开物编程整理 IGCSE / IB / A-Level 要点，并说明如何在知识点与项目上对接课程。

国内学生

开物编程可衔接信息学竞赛、校内信息课与升学相关能力培养；也可用编程作品丰富综合素质材料。

国际学校学生

按 IGCSE / IB / A-Level 大纲对齐知识点，强调项目与文档表达，方便与校内评分体系对接。

香港学生

兼顾本地升学路径与国际课程需求，灵活安排课次与进度，考试季可调整复习密度。

香港 / 国际学校常见

IGCSE

打好计算机与编程基础，衔接后续 IB / A-Level

IGCSE 阶段常见 Computer Science / ICT 相关科目，强调算法思维、编程实践与系统设计概念。适合在初中阶段系统建立文字编程与计算思维基础。

常见关注点

  • Computer Science（算法、编程、系统）
  • ICT / 信息技术相关选修
  • 与数学逻辑能力相互支撑

开物编程如何帮助

  • 开物编程用 Python / Scratch 过渡到考试要求的编程思维
  • 按知识点拆解算法与伪代码练习
  • 项目作品辅助理解「设计—实现—测试」流程
  • 针对薄弱模块做阶段性补强

给家长的提示

  • 尽早确定是否走计算机相关选课
  • 编程练习要「写」出来，而不是只看视频
  • 可与校内作业、校外项目并行安排

国际学校 / IB 体系

IB Computer Science

理论 + 项目 Internal Assessment，需要规划与持续输出

IB CS 覆盖计算思维、系统设计、网络与社会影响等，并要求完成 Internal Assessment（IA）项目。学生需要同时具备编程能力、文档表达与项目管理习惯。

常见关注点

  • SL / HL 核心主题概览
  • 编程与算法实践
  • IA 项目选题与迭代

开物编程如何帮助

  • 协助梳理 IA 选题可行性与范围控制
  • 按评分标准拆解文档与代码结构
  • Python / Java 等语言按校内要求对接
  • 阶段性 mock 与知识点查漏补缺

给家长的提示

  • IA 宜早选题、小步迭代，避免临近截止才动工
  • 代码与文档要同步整理
  • 关注学术诚信与引用规范

香港 / 英国课程体系

A-Level Computer Science

深度算法与理论，适合冲刺计算机相关专业

A-Level CS 对算法、数据结构、体系结构与编程能力要求更高，常作为申请计算机、电子、数据相关专业的重要科目。适合有一定编程基础的高中生系统提升。

常见关注点

  • 算法与编程
  • 数据结构与抽象
  • 计算机系统与网络基础

开物编程如何帮助

  • 按考试大纲建立题型训练节奏
  • C++ / Python / Java 按学校要求选主语言
  • 真题与专项模块滚动复习
  • 升学方向咨询：作品集与学习路径建议

给家长的提示

  • 理论与编程练习要双线并行
  • 错题本 + 定时模考很关键
  • 可结合个人项目提升申请材料说服力
