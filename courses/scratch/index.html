Scratch入门

Scratch 创意编程

从动画到小游戏，系统建立计算思维

适合：7–12 岁 · 零基础 / 有 ScratchJR 基础周期：24–36 课时
咨询本课程 / 报名试听

课程介绍

开物编程 Scratch 创意课：覆盖变量、条件、循环、克隆与简易算法，完成动画、互动故事与小游戏；同步培养调试习惯与项目拆解，作品可进入成果墙展示。

  • 项目制学习
  • 计算思维训练
  • 可衔接 Python
  • 作品可展示给家长

课程大纲

实际进度会按学生基础微调，以下为标准参考结构。

阶段 1

基础模块

  • 舞台、造型与声音
  • 运动与坐标
  • 外观与广播

阶段 2

逻辑模块

  • 条件判断 if / else
  • 循环与等待
  • 变量与计分

阶段 3

进阶项目

  • 平台跳跃小游戏
  • 问答闯关
  • 创意故事完整作品

知识点

变量与列表入门条件与分支循环消息广播碰撞检测简单算法拆解
