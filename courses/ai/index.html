AI综合

AI 与人工智能启蒙

理解 AI 能做什么，动手做第一个智能小项目

适合：11 岁以上 · 建议有 Python 基础周期：16–24 课时
咨询本课程 / 报名试听

课程介绍

开物编程 AI 素养与实践课：介绍机器学习基本思路与常见场景，用 Python 完成图像识别、文本分类或生成式 AI 辅助创作等入门项目；强调伦理与安全使用，作品可向家长演示。

  • 素养 + 实践
  • Python 项目
  • 前沿但不空谈
  • 强调负责任使用

课程大纲

实际进度会按学生基础微调，以下为标准参考结构。

阶段 1

认识 AI

  • AI 能做什么 / 不能做什么
  • 数据与模型直觉
  • 常见应用案例

阶段 2

动手实践

  • 用 Python 调用入门库 / API
  • 图像或文本小实验
  • 提示词与生成式工具

阶段 3

综合展示

  • 小组智能小项目
  • 讲解与演示
  • 伦理讨论与使用规范

知识点

数据与特征直觉监督 / 非监督概念入门模型评估的简单理解生成式 AI 使用AI 伦理与隐私
