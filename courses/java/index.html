课程介绍

开物编程 Java 课以项目驱动：学习语法与面向对象核心（类、对象、继承、封装、接口），完成控制台应用与简易 GUI / 小游戏，适合计划走计算机相关专业的高年级学生。

  • OOP 核心
  • 工程化习惯
  • 适合高年级
  • 可衔接大学先修

课程大纲

实际进度会按学生基础微调，以下为标准参考结构。

阶段 1

语法过渡

  • Java 环境与主方法
  • 类型与控制流
  • 数组与字符串

阶段 2

面向对象

  • 类与对象
  • 封装与访问控制
  • 继承与多态入门

阶段 3

综合项目

  • 学生管理系统雏形
  • 简易文字 RPG
  • 接口与模块划分
